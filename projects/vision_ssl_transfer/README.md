# Vision SSL Transfer

**Status**: 📋 Planned

Self-supervised pretraining followed by transfer learning with robustness and calibration analysis.

## Planned Features

- Self-supervised pretraining:
  - SimCLR-style contrastive learning
  - MAE-style masked autoencoding
- Transfer learning pipeline:
  - Fine-tuning on downstream tasks
  - Linear probe evaluation
  - kNN probe evaluation
- Robustness evaluation:
  - Blur/noise/occlusion sweeps
  - Corruption curves
- Calibration analysis on downstream tasks
- Representation visualization (UMAP)
