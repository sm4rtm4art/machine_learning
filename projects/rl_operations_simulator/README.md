# RL Operations Simulator

**Status**: 📋 Planned

Reinforcement learning for operations optimization using a custom discrete-event simulator (ER/manufacturing style).

## Planned Features

- Discrete-event simulator:
  - Job arrivals with varying characteristics
  - Resource constraints (capacity, shifts)
  - Priority rules and routing decisions
- Baseline policies:
  - FIFO
  - Shortest processing time
  - Priority rules
- RL approaches:
  - DQN for discrete actions
  - PPO for policy optimization
- Evaluation:
  - KPI distributions (not just means)
  - Constraint violation analysis
  - Generalization across demand scenarios
