# Evaluation Reports

This directory contains evaluation reports generated by project `evaluate.py` scripts.

## Structure

```
reports/
├── ocr_pipeline/
│   └── <run_id>/
│       ├── metrics.json
│       ├── slices.csv
│       ├── robustness.csv
│       └── plots/
├── tabular_boosting/
│   └── ...
└── index.md (this file)
```

## Report Contents

Each evaluation run produces:

| File | Description |
|------|-------------|
| `metrics.json` | Primary metrics (used for CI gates) |
| `slices.csv` | Per-subgroup performance breakdown |
| `robustness.csv` | Degradation under perturbations |
| `plots/` | Visualizations (calibration, confusion, etc.) |

## Viewing Reports

Reports are also logged to MLflow as artifacts. To view:

1. Start MLflow: `make mlflow`
2. Navigate to http://localhost:5000
3. Find the run and check the "evaluation" artifacts

## Git Ignore

Generated reports are excluded from git. Only this index is tracked.
